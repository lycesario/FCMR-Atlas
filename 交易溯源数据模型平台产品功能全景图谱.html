00怎么读这份图谱

这套产品的本质是把链上原始数据加工成「可举证的资金事实」：先解决钱在链上怎么表示（UTXO/账户双模型统一），再解决钱跨链跨协议怎么关联（状态机+指纹匹配），最后解决结论怎么被法庭与监管采信（置信度+版本化证据链）。模型能力是底座，可辩护性（defensible）才是定价权。

四层结构

层级这一层包含什么产品本质
第1层（d1–d5）溯源核心模型与跨链建模把链上与跨链的资金转移统一为带完整边属性的有向图，解决「钱怎么走过来的」可计算问题
第2层（d6–d10）语义还原与实体解析把原始调用还原为业务语义、把地址挂到实体与标签上，解决「图能被人读懂」的问题
第3层（d11–d15）数据模型与举证查询用本体、事件溯源与版本化 schema 组织数据，用多跳查询与 Taint 分析产出可复现的结论
第4层（d16–d18）治理、性能与规模置信度分档、审计元数据与万亿边低时延计算，保证结论可信、可辩护、够快
三条先决判断：① 归属主数据必须先于查询产品存在——没有实体归属与标签库，图再漂亮也答不出「这是谁」；
② 边属性完整性与版本化必须先于规模化——事后补证据链的成本是重建；
③ 置信度框架必须先于执法交付——没有分档与方法学卡的报告在法庭上不成立。
最大的死亡陷阱：把「图谱数据量大」当成成功信号。几千亿数据点如果边属性残缺、归因无置信度、结论不可复现，它只是昂贵的存储负债——客户要的是能在法庭上站得住的一条结论，不是十亿条无法质证的边。

07资质与监管地图

该领域是四个监管域的交汇点：① 反洗钱域（FATF 建议 15/16、旅行规则、各国 AML 法，要求可追溯与 SAR 上报）；② 制裁域（OFAC SDN 与混币器指定，要求小时级名单联动）；③ 数据与隐私域（GDPR、数据安全法，限制情报与个人数据流转）；④ 牌照域（MSB/MiCA/MAS/SFC VATP，决定能向谁卖、怎么卖）。溯源结论同时是监管要求的产品，也是监管审查的对象。

09如果要做，从哪开始

链路长、环节多，冷启动的关键是用一个场景把主线跑通，再放大。

收敛步骤
  • 第一步：冻结核心对象与本体口径（地址/实体/价值边/标签/关联/归属结论六对象的 ID 与字段），先于一切功能开发；
  • 第二步：打通 2–3 条主流链的端到端溯源管道（边七件套+对账+幂等重放），把数据质量做穿，不横向铺链；
  • 第三步：建设实体归属主数据与标签库（证据分级+版本化+抽检），这是所有查询与报告的上游；
  • 第四步：上线多跳穿透查询与 Taint 分析（带置信度分档与查询审计），先服务 3–5 个标杆执法/交易所案件；
  • 第五步：补齐跨链原子化关联与取证报告自动化（版本锁定+方法学卡），进入持续订阅与追赃服务循环。
候选路径
  • 路径 A（执法取证切入）：以取证报告与专家服务打开执法机构与律所，高毛利、强口碑，再下沉到机构订阅；
  • 路径 B（交易所 KYT API 切入）：以低门槛筛查 API 渗透中小交易所与协议团队，走量后再上取证能力；
  • 路径 C（数据平台切入）：先卖图数据订阅与开放 schema，做生态采用率，再叠加风险评分产品；
  • 路径 D（追赃服务切入）：绑定律所与交易所协作网络，按案件计费做冻结令支持，以案件养产品。
四条路径的共同点：都必须先拥有「可举证的归属与证据链」这一第一资产——没有它，执法路径出不了法庭、API 路径经不起审计、数据路径卖不出溢价、追赃路径打不赢冻结令。
