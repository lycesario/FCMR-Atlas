00怎么读这份图谱

这套产品的本质是「私钥在你手、交易不假手他人」。它把传统交易所的撮合与托管拆解为钱包内的自托管能力，核心价值来自用户对资产的绝对控制与可组合的交易范式。

四层结构

层级这一层包含什么产品本质
第1层 密钥与资产底座（d1–d4）HD 钱包引擎 / 私钥与密钥管理 / 多链资产索引 / 交易构建与广播把种子确定性派生为可控密钥，并把链上账本翻译成可读资产与可上链交易
第2层 非托管交易与签名范式（d5–d8）DEX 聚合与内置 Swap / MPC 钱包 / 智能合约钱包与账户抽象 / 多签与机构托管对照在不离开钱包的前提下完成兑换，并用 MPC、合约账户、多签重塑签名与授权形态
第3层 恢复、P2P 与权属证明（d9–d13）社交恢复与无助记 / P2P 场外与原子交换 / 钱包安全与钓鱼防护 / 合约授权与资产风控 / 地址所有权证明用守护人、原子结算、签名审查与所有权证明解决「丢钥即丢资、授权即交权」的死结
第4层 合规、隐私与智能体（d14–d18）Travel Rule 非托管落地 / 合规尽调 EDD / 隐私与选择性披露 / Agentic 钱包与自动化交易在自托管前提下嵌入旅行规则、增强尽调、ZK 披露与授权智能体，使自由与合规并存
三条先决判断：
1. 第一资产是私钥掌控权——任何把私钥交出的设计都不再是自托管；
2. 最短闭环是签名审查——所有交易必须经语义化签名前审查，否则盲签即交权；
3. 必须先于客户存在的合规/安全能力——KYT、制裁筛查与授权风控须在首个用户前就位。
一条死亡陷阱：把「无托管」当成「无责任」。非托管不豁免 FATF 旅行规则与 EDD，误以为不碰 KYC 就合规，会在 MiCA/OFAC 下被重罚。

私钥/种子用户资产的唯一控制权凭证，决定资产归属错配或泄露即不可逆转移，且无法挂失，是全部安全的总开关

国际市场

三条最常被低估的合规红线：
1. 非托管不等于免 KYC——超阈值 unhosted 交互仍需 EDD 与旅行规则；
2. 大陆禁业红线——向境内居民提供交易/兑换/法币出入金属非法金融活动；
3. OFAC 瞬时收紧——制裁名单更新须毫秒级拦截，滞后即连带被罚。

09如果要做，从哪开始

链路长、环节多，冷启动的关键是用一个场景把主线跑通，再放大。

收敛步骤
  • 第一步 锁定第一资产：以私钥掌控权为不可退让的产品底线
  • 第二步 建最短闭环：所有签名必须经语义化前审查与模拟
  • 第三步 嵌入合规前置：KYT/制裁筛查/授权风控先于首个用户
  • 第四步 选 MVP 形态：钱包内 DEX 聚合或授权管理切入变现
  • 第五步 留合规档案：EDD/SAR/留存版本化支撑 7 年审计
候选路径
  • 路径 A 消费者自托管钱包（HD+MPC+社交恢复）
  • 路径 B 机构 MPC 金库（分片+审计留痕+EDD）
  • 路径 C 合规中间件（KYT/TR/PoA SDK 嵌入他者钱包）
  • 路径 D Agentic 授权交易（预算受限的智能体框架）
四条路径的共同点：都围绕「第一资产——私钥掌控权」展开，并把合规与签名审查作为不可外包的内生能力。
